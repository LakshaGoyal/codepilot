# Brag Plan: CodePilot

## What is this app?
CodePilot puts your Claude Code AI assistant directly inside a CometChat group chat. Text code requests from your phone, watch live execution steps, review interactive diff cards, and ship commits with a single team approval tap.

## The angle
A cinematic, trailer-scale product film showing how software development escapes the terminal and enters the group chat via CometChat real-time messaging. Dramatic high-contrast typography, sleek monochrome glass UI elements, and a punchy 5-act beat-synced storyboard.

## Hook (first 2-3 seconds)
A dramatic dark opening frame with deep atmospheric glow and giant bold typography slamming in: "YOUR CODING AGENT LIVES IN THE GROUP CHAT." accompanied by a glowing "COMETCHAT INTEGRATION" badge.

## Key moments (the middle)
- Incoming prompt in phone group chat from Laksha: `@CodePilot make the signup button orange` with a prominent CometChat integration callout banner.
- Agent console drawer sliding out with live tool steps: `Reading workspace/src/App.css`, `Editing button styles`, `npm test: 7/7 passed`, `Synced to CometChat live custom card`.
- Interactive `agent_result` card with live green/red diff, test status badge, and simulated tap on `[ Ship it ]` by Dravid.
- Instant confirmation card: `agent_event: shipped a1b2c3d`.

## Outro / punchline
"NO DASHBOARDS. REAL-TIME COMMUNICATION POWERED BY COMETCHAT" transition into the CODEPILOT logo mark with "Seamless real-time collaboration with CometChat & Claude Code".

## User flow worth showing
`@CodePilot make the signup button orange` in phone chat → CodePilot runs live steps & tests in console → Rich result card with diff posted to CometChat → Teammate Dravid taps "Ship it" → Shipped commit `a1b2c3d` generated.

## Tone
- Preset: cinematic
- Creative direction: Dramatic trailer-scale product film with deep atmospheric lighting, high contrast typography, precision beat-synced motion, and audio-reactive glow.
- Interpretation: Wide vertical framed shots, bold typographic reveals, smooth glass transitions, hold long enough for complete copy legibility.

## Format: vertical — 1080x1920
## Duration: 25 seconds

## Visual identity (from the project)
- Background: `#000000` (deep true black)
- Accent: `#ffffff` / `#7c5cff` (monochrome + CometChat violet accent)
- Text: `#ffffff` (primary white), `#9a9a9a` (secondary muted), `#c4b5fd` (CometChat highlight)
- Display font: `Inter`, system-ui, sans-serif
- Body font: `Inter`, system-ui, sans-serif
- Code font: `ui-monospace`, `SFMono-Regular`, `Consolas`, monospace
- Strongest visual element: Sleek dark monochrome glass panels (`rgba(255,255,255,0.035)`), glowing green test badges (`#00e676`), red/green git diff blocks, and glowing CometChat integration badges.

## Storyboard

### Scene 1 — Cinematic Hook & CometChat Badge — 4.5s (0.0s - 4.5s)
Dark atmospheric background. Title text slams in: "YOUR CODING AGENT LIVES IN THE GROUP CHAT." Subtitle / badge pops in: "COMETCHAT INTEGRATION".

### Scene 2 — The Command & Real-time Messaging — 4.5s (4.5s - 9.0s)
Vertical mobile view of the "Ship It" group chat (Laksha, Dravid, @CodePilot). Phone chat bubble types in: `@CodePilot make the signup button orange`. CodePilot status indicator shows typing. Prominent CometChat integration callout banner slides in.

### Scene 3 — The Brain at Work — 5.5s (9.0s - 14.5s)
Console card streams live steps: `Read App.css`, `Edit button styles`, `PASS (7/7 tests passed)`, `Synced to CometChat live custom card`.

### Scene 4 — Result & Team Approval — 6.0s (14.5s - 20.5s)
Phone group chat view with the rich `CodePilot Result` card. Animated cursor taps `[ Ship it ]`. Card updates to `Shipped commit a1b2c3d (Approved by Dravid)`.

### Scene 5 — Outro & Core Platform Callout — 4.5s (20.5s - 25.0s)
"NO DASHBOARDS. REAL-TIME COMMUNICATION POWERED BY COMETCHAT" transition into CODEPILOT logo lockup: "Seamless real-time collaboration with CometChat & Claude Code".
